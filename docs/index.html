SKILLSHARK

Share an agent skill like you'd share a file. One command out, one command in — unlisted, revocable, self-verifying links.

No server. No registry. No new accounts. The GitHub you already have is the infrastructure: skills travel as secret gists, receivers need nothing but Node.

$ npx skillshark install <link>

how it works

    
Three moves, zero ceremony

    

      

        
[1/3] PACK

        
share

        
skillshark share /j finds the skill in .claude/skills, infers the manifest (you never write one), scrubs .env and key-shaped files, and uploads a tarball as a secret gist. The link lands on your clipboard.

      

      

        
[2/3] PASTE

        
the link

        
It's a plain gist URL with a fingerprint riding the fragment: #fp=3f9a7c21. Unlisted, attributable to your GitHub identity, revocable at any moment. The gist page doubles as a free browser preview.

      

      

        
[3/3] INSTALL

        
install

        
npx skillshark install <link> fetches anonymously, verifies every byte, shows a preview, asks consent, and copies files into the right .claude/ path. Works from any public repo too: gh:owner/repo/path@ref.

the surface area

    
Four commands. That's the tool.

    

      

        
share <path|name>

        
Package → secret gist → link on clipboard. Advisory expiry, dry-runs, secret scanner.

        
$ skillshark share /j --expires 24h
$ skillshark share ./prompts --dry-run

      

      

        
install <source>

        
Verify, preview, confirm, copy. Never executes anything. Gist links, bare ids, or repo paths.

        
$ skillshark install <gist-url|id>
$ skillshark install gh:acme/skills/review@main

      

      

        
inspect <source>

        
Look before you leap — full download + verification, zero writes. Read any packaged file.

        
$ skillshark inspect <link> --cat SKILL.md

      

      

        
revoke <id|name>

        
Deletes the gist via your gh auth. The link dies; installers get an honest message.

        
$ skillshark revoke j
# → "This share was deleted by the sender."

trust model

    
Paranoid by construction

    
    
      
  • Never executes package content. Install = copy files. No postinstall hooks, no scripts, ever.
    • 
      
  • Executable bits stripped by default. Flagged in the preview; --allow-exec is an explicit opt-in.
    • 
      
  • Every byte verified. Per-file sha256 + a tree fingerprint, checked after guarded extraction — path traversal, symlinks, absolute paths, decompression bombs all abort with nothing written.
    • 
      
  • Self-verifying links. The #fp= fragment is recomputed from downloaded bytes — if the gist was edited after sharing, the install hard-fails.
    • 
      
  • Receivers need no GitHub account. The receive path is anonymous HTTPS only, and provably never shells out (enforced by tests).
    • 
    

    

      ⚠ secret ≠ private. A secret gist is unlisted, not encrypted — anyone holding the URL can read it,
      and a skill is instructions an AI will obey. SkillShark makes installs informed and tamper-evident,
      not safe-from-strangers. Share with people you trust; read what people send you.
